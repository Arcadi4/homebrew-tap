# Homebrew Tap

My personal Homebrew tap, mostly projects I am using or interested in.

## Usage

```sh
brew tap arcadi4/tap
```

Install a formula or cask with:

```sh
brew install <name>
```

## Formulae

| Name | Description |
| --- | --- |
| `cliproxyapi-yumetsuki` | More stable branch of CLIProxyAPI maintained by [@Hoshino-Yumetsuki](https://github.com/Hoshino-Yumetsuki). |
| `headroom` | Local context compression proxy for LLM applications. |
| `kiro.rs` | Anthropic-compatible API proxy service for Kiro. |
| `markitdown` | Convert files to Markdown for LLMs and text analysis. |

## Casks

| Name | Description |
| --- | --- |
| `clashx` | Rule-based proxy utility. |
| `keytype` | System-wide tab autocomplete utility. |
| `pi-mono` | AI agent toolkit with CLI, unified LLM API, TUI, and web UI libraries. |
| `sidekick-ai` | Native macOS app for chatting with a local LLM that can use information from files, folders, and websites on your Mac. |
| `vivo-office-kit` | Multi-device client for screen mirroring, file transfer, and remote control. |
